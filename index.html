Quick start

放置 Widget 即启动

01

放置控件

在 UMG 中放置原生 Mass Battle Frame Minimap，或使用 Content/Core/MassBattleFrameMiniMap.uasset。

02

确定区域

关卡中的 AMapRegion 定义世界范围；没有 Actor 时读取当前地图的 MapRegion.ini。

03

显示

Widget 的 UMG 位置与尺寸就是 GPU 最终绘制区域。构造时立即推送一帧，此后按更新频率刷新缓存。

CPU 做什么？

只遍历 Renderer 与 Render Batch，并用 TArray::Append 合并连续内存块。CPU 不逐单位投影、过滤或重组；每个单位的坐标、尺寸、Team 与隐藏判断都留在 GPU。

Shader contract

GPU 绘制规则

A

坐标与旋转

UV = (WorldXY - MapMin) / MapSize
ScreenUV = (UV.y, 1 - UV.x)

世界 XY 映射后逆时针旋转 90°，直接换算到 Widget 像素区域。

B

逻辑像素向上取整

LogicalSize = max(
  ceil((2 × RadiusUU) × Resolution / MapSize),
  1
)

分辨率为 256 时，任何非零尺寸至少占整张地图每轴的 1/256。

C

Team 直接索引

TeamID = asuint(DynamicParams0.W) & 1023
Color  = TeamColors[TeamID]

颜色表覆盖 0..1023；缺失索引使用 (0.7, 0.7, 0.7, 1)。

D

单位与视野

  • 所有未隐藏单位：正方形色块
  • 仅 Viewing Team：圆形视野
  • 最后画雾：视野模板内跳过

联盟关系没有输入，因此不会猜测其他 Team 是否共享视野。
