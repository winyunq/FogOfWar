战争迷雾 · MassBattle · GPU Post Process

面向大规模 RTS 战场的 FogOfWar 文档

Winyunq FogOfWar 使用 MassBattle HashGrid 作为单位位置真理源，用 GPU 圆形视野源后处理绘制玩家主画面迷雾，并提供基于 HashGrid 降采样的小地图数据链路。

Quick Start

四步接入主画面迷雾

  1. 1

    放置迷雾 Actor

    在关卡中放置 Content/Core/BP_FogOfWar.uasset，或直接放置 AFogOfWar。未设置 GridVolume 时，Actor 会以自身位置和 FallbackGridSize 建立默认世界范围。

  2. 2

    绑定后处理材质

    将 PostProcessingMaterial 指向 Content/Core/Materials/M_FogOfWar.uasset，保持 bAutoActivate=true，或在蓝图/C++ 中手动调用 Activate()。

  3. 3

    给 Mass 原型添加视野 Trait

    在 Mass 实体原型中添加 UMassVisionTrait，设置 SightRadius > 0。需要出现在小地图中的单位保留 bShouldBeRepresentedOnMinimap=true。

  4. 4

    运行并查看数据

    运行时 AFogOfWar 会从 MassBattle HashGrid 收集相机相关的视野源，上传到后处理材质使用的数据纹理，并写入性能 CSV。

Scene Fog

主画面采用 GPU 圆形视野源

当前主路径不再使用旧的多阶段 RT 插值链。 InterpolationMaterial、AfterInterpolationMaterial、SuperSamplingMaterial 和 FOW_FinalVisibilityTexture 不再是主画面迷雾路径。

CPU 只做收集

插件从 MassBattle HashGrid 中遍历相机相关区域，读取真实单位位置与 SightRadius，将可影响当前画面的圆形视野源压缩为一条 RGBA32F 数据纹理。

GPU 逐像素判断

后处理材质对当前像素的世界坐标执行圆内测试。像素落入任意视野圆则显示原场景，否则用 NotVisibleRegionBrightness 降暗。

float Visible = 0.0;

if (FOW_EnableSceneGpuVisionSources > 0.5)
{
    [loop]
    for (int SourceIndex = 0; SourceIndex < (int)FOW_SceneGpuVisionSourceCount; ++SourceIndex)
    {
        float4 Source = FOW_SceneGpuVisionSourceTexture.Load(int3(SourceIndex, 0, 0));
        float2 Delta = CurrentPixelWorldXY - Source.xy;
        float RadiusSq = Source.z * Source.z;
        Visible = max(Visible, dot(Delta, Delta) <= RadiusSq ? 1.0 : 0.0);
    }
}

Material Contract

后处理材质参数

自定义后处理材质时，请保持以下参数名与类型一致。推荐使用 Post Process 材质域，Blendable Location 设置为 After Tonemapping。

参数 类型 含义
FOW_SceneGpuVisionSourceTexture Texture2D RGBA32F 每个 texel 为 (WorldX, WorldY, SightRadius, Reserved)。
FOW_SceneGpuVisionSourceCount float 本帧上传的视野源数量。
FOW_EnableSceneGpuVisionSources float 大于 0.5 时启用 GPU 圆形揭雾。
FOW_NotVisibleRegionBrightness float 不可见区域亮度，范围通常为 0 到 1。
FOW_BottomLeftWorldLocation float3 迷雾世界范围左下角坐标。
FOW_GridSize / FOW_GridWorldSize float3 迷雾世界范围尺寸。

Minimap

小地图 Widget 接入

UMG 设置

  1. 创建一个继承 UMinimapWidget 的 UMG。
  2. 在 Widget 中添加 Image 控件，命名为 MinimapImage。
  3. 将 MinimapMaterial 指向 Content/Core/Materials/MinimapTarget.uasset。
  4. 添加到 Viewport，Widget 会在 Tick 中按 UpdateInterval 更新。

数据路径

UMinimapWidget 通过 UMinimapDataSubsystem::UpdateMinimapFromHashGrid 遍历 MassBattle HashGrid，把单位位置、颜色、图标半径和视野源写入数据纹理。

关键上限 MaxSceneGpuVisionSources

控制材质逐像素循环上限。过高会增加 GPU 后处理成本。

Troubleshooting

常见问题检查顺序

有后处理材质，但迷雾不更新
  • 确认关卡里存在 AFogOfWar 或 BP_FogOfWar，且已经 Activate()。
  • 确认视野单位带 UMassVisionTrait，并且 SightRadius > 0。
  • 确认 PostProcessingMaterial 使用当前 M_FogOfWar 或参数契约完全一致的自定义材质。
部分单位没有揭雾
  • 检查单位是否已经进入 MassBattle HashGrid。
  • 检查 FOW_SceneGpuVisionSourceCount 是否达到 MaxSceneGpuVisionSources 上限。
  • 必要时提高 SceneGpuVisionSourceRadiusPadding，避免 cell 或采样边缘误差造成漏收。
小地图没有显示单位
  • 确认 Widget 中的 Image 名称是 MinimapImage。
  • 确认 MinimapMaterial 已设置，且单位保留 bShouldBeRepresentedOnMinimap=true。
  • 确认地图边界已由 AMinimapRangeConfig、INI 或 HashGrid 自动推导成功。
